# CRM и среда разработки — заготовка

Учебная заготовка для исследования архитектуры CRM, инструментов поиска лидов и среды разработки. Рабочие базы, токены, личные контакты и настройки развёртывания в этот набор не включены. Контактные данные в примерах заменены вымышленными значениями.

## Состав

- `crm/` — код серверной части CRM из работающего образа и обезличенная собранная версия интерфейса в `crm/ui/`.
- `leadgen/` — код и тесты лидогенератора из работающего образа.
- `development/` — код среды разработки и её интеграции. В состав входит сторонний проект raytsystem; условия использования и сведения об авторах находятся в соответствующих файлах лицензии и уведомлениях.

## Состояние

Это предварительная заготовка, а не готовый установочный комплект. Исходный проект интерфейса CRM не найден; приложена собранная версия. Полный набор конфигурации и сквозной сценарий установки ещё не подтверждены. Перед использованием настройте собственные интеграции, доступы и инфраструктуру. Данные из примеров не предназначены для реальной рассылки.

Проверка выполнена частично: синтаксис Python, отдельные тесты лидогенератора и локальное открытие интерфейса с отключёнными внешними запросами. Полный запуск, автоматическая установка и эксплуатационная безопасность не подтверждены.

## Локальный просмотр интерфейса

```sh
cd crm/ui
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/admin/`. Это просмотр статической сборки: вход и работа с данными требуют отдельно настроенного API, поэтому такой просмотр не является демонстрацией полностью работающей CRM.

## Исходные проекты и права

В среду разработки включён проект **raytsystem** авторства Roma Rayt. Его лицензия Apache 2.0 и уведомления сохранены в `development/upstream/`. В лидогенераторе сохранены сведения о стороннем коде в `leadgen/THIRD_PARTY_NOTICES.md` и соответствующая лицензия в `leadgen/licenses/`. Условия для остального кода отдельно не определены.
